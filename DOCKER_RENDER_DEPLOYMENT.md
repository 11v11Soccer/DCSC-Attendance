# Docker Deployment Guide for Render

This guide will help you deploy the DCSC Attendance Dashboard on Render using Docker with password protection.

## 🔐 Password Protection

The application is now protected with HTTP Basic Authentication. Users will need to enter a username and password before accessing the dashboard.

## 📋 Prerequisites

- GitHub account
- Render account (free tier works fine)
- This repository pushed to GitHub

## 🚀 Step-by-Step Deployment

### Step 1: Push Your Code to GitHub

```bash
git add .
git commit -m "Add Docker support and password protection"
git push origin main
```

### Step 2: Create New Web Service on Render

1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub repository
4. Select the `DCSC-Attendance` repository

### Step 3: Configure the Web Service

**Basic Settings:**
- **Name**: `dcsc-attendance-dashboard` (or your preferred name)
- **Environment**: `Docker` (Render will auto-detect the Dockerfile)
- **Region**: Choose closest to you
- **Branch**: `main`

**Instance Type:**
- **Free** (for testing) or **Starter** (for production)

### Step 4: Set Environment Variables

In the "Environment Variables" section, add these **THREE** variables:

1. **SECRET_KEY** (Auto-generated by render.yaml)
   - This is automatically generated for Flask sessions

2. **BASIC_AUTH_USERNAME**
   - **Key**: `BASIC_AUTH_USERNAME`
   - **Value**: Your chosen username (e.g., `dcsc_admin`)
   - Click **Add**

3. **BASIC_AUTH_PASSWORD**
   - **Key**: `BASIC_AUTH_PASSWORD`
   - **Value**: Your strong password (e.g., `DCSC2025!SecurePass`)
   - Click **Add**

> ⚠️ **IMPORTANT**: Choose a STRONG password! This protects your confidential attendance data.

### Step 5: Deploy

1. Click **"Create Web Service"**
2. Render will:
   - Clone your repository
   - Build the Docker image
   - Deploy the application
   - Assign a URL (e.g., `https://dcsc-attendance-dashboard.onrender.com`)

### Step 6: Wait for Deployment

- First deployment takes 3-5 minutes
- Watch the logs for any errors
- Look for: **"Your service is live"** message

### Step 7: Access Your Dashboard

1. Click the URL provided by Render
2. You'll see a **login prompt**
3. Enter:
   - **Username**: The value you set for `BASIC_AUTH_USERNAME`
   - **Password**: The value you set for `BASIC_AUTH_PASSWORD`
4. Click **Sign In**
5. You should now see the dashboard!

## 🔄 Updating Your Deployment

Whenever you make changes and push to GitHub:

```bash
git add .

```

Render will **automatically redeploy** your application (usually takes 2-3 minutes).

## 🛠️ Troubleshooting

### Issue: Build Failed

**Solution**: Check the build logs on Render for specific errors.

### Issue: Application Crashes

**Solution**: 
1. Check the logs in Render dashboard
2. Make sure all environment variables are set correctly
3. Verify the Docker build locally first:
   ```bash
   docker build -t dcsc-attendance .
   docker run -p 8080:8080 -e BASIC_AUTH_USERNAME=admin -e BASIC_AUTH_PASSWORD=test dcsc-attendance
   ```

### Issue: Can't Login

**Solution**:
1. Verify `BASIC_AUTH_USERNAME` and `BASIC_AUTH_PASSWORD` are set in Render environment variables
2. Check for typos in username/password
3. Passwords are case-sensitive!

### Issue: "Service Unavailable"

**Solution**: 
- Free tier services spin down after 15 minutes of inactivity
- First request after inactivity takes ~30 seconds to wake up
- Consider upgrading to paid tier for always-on service

## 🔒 Security Best Practices

1. **Use Strong Passwords**:
   - Minimum 12 characters
   - Mix of uppercase, lowercase, numbers, special characters
   - Example: `DCSC@ttend2025!Secure`

2. **Don't Commit Passwords**:
   - Never add actual passwords to `.env` or code
   - Always use Render's environment variables

3. **Rotate Passwords**:
   - Change password periodically
   - Update in Render environment variables

4. **Share Credentials Securely**:
   - Use secure channels (encrypted email, password manager)
   - Don't share in plain text

## 📊 Testing Locally with Docker

To test the Docker setup locally before deploying:

```bash
# Build the Docker image
docker build -t dcsc-attendance .

# Run with password protection
docker run -p 8080:8080 \
  -e BASIC_AUTH_USERNAME=admin \
  -e BASIC_AUTH_PASSWORD=testpass123 \
  dcsc-attendance

# Access at: http://localhost:8080
# Login with: admin / testpass123
```
